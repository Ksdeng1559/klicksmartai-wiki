# Grant Funding Sources

## Purpose

This page organizes the funding sources that support the SBIR and Grants workflow.

The goal is to create a structured source map for the Funding Intelligence Operating System so every opportunity can be routed into the same process:

```text
Funding Source → Eligibility Review → Readiness Score → Logic Model → Capital Stack → Proposal Package
```

## 8. Funding Source Classification

Every funding source should be classified using this structure:

| Field | Description |
|---|---|
| Source type | SBIR, grant, contract, state program, county program, tribal program, CDFI, foundation, investor |
| Agency / institution | Funding body |
| Applicant type | Small business, county, nonprofit, tribe, university, developer, public-private partnership |
| Project fit | Housing, energy, waste, AI, infrastructure, resilience |
| Funding role | Planning, R&D, pilot, implementation, match, leverage, debt, equity |
| Deadline | Due date or rolling |
| Readiness impact | What must be true before applying |
| Capital stack role | Where this funding fits in the project stack |

---

## 9. Funding Source Workflow

```text
1. Capture source
2. Classify source type
3. Extract eligibility
4. Identify applicant requirement
5. Match to project type
6. Score fit
7. Identify readiness gaps
8. Assign capital stack role
9. Generate next action
10. Store in knowledge graph
```

## 11. Operating Principle

Do not treat a grant as the whole solution.

Treat each source as one layer in a larger funding strategy:

```text
Grant + SBIR + Contract + County Support + CDFI + Impact Capital + Private Capital
```

The Funding Intelligence OS should continuously connect:

```text
Sources ↔ Problems ↔ Technologies ↔ Communities ↔ Agencies ↔ Partners ↔ Capital Stacks ↔ Proposals ↔ Outcomes
```
