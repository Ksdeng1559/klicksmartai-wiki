## The fill-in-the-blank template
Copy this and swap in the slots for your offer:
```plain text
Subject: {quick_win_deliverable} for {company}, {free_or_price}

Hey {first_name},

If we {delivered_the_dream_outcome} in the next {short_timeframe} -
{at_low_or_no_cost} - would that be worth a quick call?

We'd handle {task_1}, {task_2}, {task_3}, and {task_4}.
All you have to do is {one_small_action} - {time_commitment}.

Happy to send over {proof_deliverable} from {adjacent_comparable_brand}
if useful.

{name}
```

## Pre-send audit: 8 questions
Before you send this to 500 inboxes, run it through these questions. If the answer to any of them is "no," rewrite that variable before sending.
1. Does the subject line name a specific deliverable or outcome?
2. Is the dream outcome demonstrated through evidence - never claimed?
3. Is there a specific, comparable brand referenced or implied in the email?
4. Is the first deliverable something the prospect can receive within 7 days?
5. Have you deleted every reference to multi-month processes?
6. Does one sentence list 3-5 specific tasks you handle on your side?
7. Is the prospect's total commitment a single bounded action?
8. Can the CTA be answered with a one-word reply?
Eight yeses means you're ready to send. Anything less and you're leaving replies on the table.
---
## How to iterate without learning nothing
If the first version of a script underperforms, rewrite **one variable at a time** so you can isolate what actually moved the metric. The trap most operators fall into is rewriting everything at once and losing all signal about what changed.
- **Week 1** - test two versions of Variable 1 (the dream outcome framing). Keep everything else constant.
- **Week 2** - test two versions of Variable 3 (a shorter time window vs a longer one).
- **Week 3** - test two versions of Variable 4 (different effort-compression language).
- **Week 4** - test two versions of Variable 2 (swap the proof-by-adjacency brand for a closer match).
One variable. Same list quality. Enough volume to get statistical signal. Pick the winner, lock it in, move to the next variable.
---
## Final thought
The equation itself isn't new. It hasn't been new since Hormozi published it. What changed is that the surface-level application - *state the dream, add a testimonial, close with 90 days* - stopped working because every inbox recognizes the pattern on sight.
The 2026 version keeps the same four variables and quietly rewires how each one is delivered. Dream outcome shown through evidence, not claimed. Likelihood built into the offer shape, not propped up with testimonials. Time collapsed to a single week. Effort moved almost entirely onto your side.
Rewrite your main script using the template on this page, run it through the 8-question audit, and send it. Replies move.
