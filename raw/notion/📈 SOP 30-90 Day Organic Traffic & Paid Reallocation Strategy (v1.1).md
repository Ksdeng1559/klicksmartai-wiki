# 1. Purpose
This SOP defines the repeatable process for building an integrated organic + paid traffic system that acquires visibility across AI search engines (ChatGPT, Perplexity, Gemini) and Google, while reallocating paid budget from underperforming to high-ROI channels.
**Target outcomes by Day 90:**
- 500–1,000 monthly organic visitors to the primary page
- 15–25% blended CPL reduction via channel reallocation (not budget increase)
- 10–15 backlinks from parasite SEO content
- Primary page indexed by all three major AI engines
---
# 2. Scope & Constraints
**Applies to:** Any client engagement following the compact keyword cluster + primary page hub model with existing vertical pages.
**Hard budget rule:** Month 1 paid spend is capped at \$1,500 across ALL channels combined. Scaling beyond this requires passing the gates in Section 5. Reallocation over scaling — shift budget from losers to winners before adding budget.
**Known time lags:** Featured snippets take 30–45 days. Organic volume takes 60–90 days. Do not pivot early based on organic silence before Day 45.
---
# 3. Roles & Prerequisites
Before Day 1, confirm all of the following:
- [ ] \$1,500/month test budget approved; management aware scaling requires proof
- [ ] Authority to reallocate between channels without approval delays
- [ ] Authority to pause/kill underperforming channels after 30 days
- [ ] Access: Google Ads, Facebook Ads, Bing Ads accounts
- [ ] Access: Google Analytics 4 (or equivalent) + CRM data
- [ ] CMS access for primary page build
- [ ] Content creation resources identified (internal or contractor)
---
# 4. Procedure by Phase
## Phase 1 — Foundation & Research (Days 1–14)
**Steps:**
1. Build keyword cluster map: 50+ related terms organized by intent (TOFU/MOFU/BOFU)
2. Aggregate top 15–20 PAA questions, prioritized by volume and competition
3. Run competitor gap analysis — identify 5+ opportunities where non-commercial sites rank
4. Audit existing vertical content; map cross-linking opportunities
5. Extract paid channel baseline: CPL, volume, ROAS by channel
**Exit criteria:** All five deliverables complete; CPL variance by channel documented.
**Tools:** DataForSEO API, SerpAPI, Google Search Console, ad platform exports.
## Phase 2 — Primary Page Architecture (Days 8–21)
**Steps:**
1. Wireframe 8–12 page sections: hero, FAQs, comparisons, trust signals, CTAs
2. Draft 15+ FAQ answers (150–300 words each) mapped to PAA research
3. Write schema markup spec: FAQPage, LocalBusiness, Service, Organization, Review (JSON-LD)
4. Build internal linking map with 20+ cross-linking opportunities and anchor text
5. Define CTA hierarchy by conversion stage (awareness to consideration to decision)
**Exit criteria:** Wireframe approved; FAQ bank drafted; schema spec field-complete.
## Phase 3 — Parasite SEO & Distribution (Days 15–45)
**Steps:**
1. Rank 8–12 platforms by traffic potential and effort (Medium, LinkedIn, Reddit, Quora, forums)
2. Create 4–6 content guides with platform-specific angles
3. Execute brand mention strategy — natural links back to primary page
4. Run HARO/Connectively pipeline: minimum 3 pitches per week
5. Track backlinks weekly in the backlink tracker
**Exit criteria:** 4–6 guides live across 8–12 platforms; 10–15 backlinks by Day 60; 3+ HARO mentions.
## Phase 4 — AI Overview Optimization (Days 20–60)
**Steps:**
1. Map each PAA question to a featured-snippet-optimized answer (150–200 word zone)
2. Structure answers as intro + bullets or numbered list per question type
3. Implement and validate schema (Google Rich Results Test — target 95%+ compliance)
4. Monitor AI engine indexing weekly (ChatGPT, Perplexity, Gemini)
5. Analyze current snippet holders and iterate on answer relevance and length
**Exit criteria:** 2–3 featured snippets won by Day 45; indexed by all three AI engines by Day 60.
## Phase 5 — Paid Reallocation (Days 1–90, ongoing)
**Month 1 allocation (\$1,500 cap):**
- Google Ads: \$500–600 — search intent, conversion test
- Facebook/Instagram: \$400–500 — audience testing, lookalike seed data
- Bing Ads: \$200–300 — lower competition margin test
- YouTube/Remarketing: \$200–300 — audience building for lookalikes
- Reserve: \$100–200 — rapid pivot buffer

- Run 2–3 creative variations simultaneously; rotate messaging every 7 days
