# Dubb

**Dubb** is a video communication platform designed for sales leaders. It transforms static sales outreach (email, LinkedIn, SMS) into personalized video experiences — driving 30-300% increases in conversion rates through video testimonials and replies.

---

## Core Product

Video-first sales communication platform. Record, share, and track personalized video messages at scale across email, LinkedIn, SMS, and web.

---

## Feature Inventory

### Video Creation
| Feature | Description |
|---------|-------------|
| **Dubb Chrome Extension** | Screen/webcam recording, share directly from Gmail, LinkedIn, CRMs |
| **Dubb Desktop App** | Full screen + webcam recording for Mac/PC; supports PowerPoint, PDFs, browser |
| **Dubb Mobile App** | Create/upload videos from mobile device |
| **Virtual Background** | Real-time background blur or custom image — zero equipment needed |
| **Teleprompter** | Script display during recording for polished delivery |
| **Scripts** | Create and share video scripts with team |

### AI Features
| Feature | Description |
|---------|-------------|
| **SIA** | AI-powered live chat support on landing pages — real-time support, guides users to booking/forms/checkout |
| **IRA** | AI writing assistant — generates blog posts, social captions, email copy, YouTube scripts from topic + industry + tone |
| **Caira** | AI real-time feedback on communication delivery — analyzes clarity, empathy, professionalism, positivity, persuasiveness |
| **Dubb Transcribe** | Auto-transcribe videos to any language (price per minute) |
| **Avatar Video Generator (Ava)** | Generate talking avatar videos from script — select voice, language, avatar model |

### Distribution & Integration
| Feature | Description |
|---------|-------------|
| **LinkedIn Integration** | 5 integration points: messaging, comments, connection requests, Sales Navigator, Recruiter |
| **Dubb + YouTube** | Embed interactive Dubb Action Pages into any YouTube video |
| **Broadcast Email Campaigns** | Drag-and-drop email templates with personalized video, name-in-thumbnail, CTA |
| **Two-Way SMS Campaigns** | Broadcast SMS with video link; real-time activity tracking, individual contact SMS |
| **iMessage Extension** | Send Dubb Action Pages via iMessage on iOS |
| **Bio Link** | Video landing page for Instagram, Twitter, Facebook, YouTube bio links |
| **QR Codes** | Auto-generated QR codes for print materials → mobile video |

| Feature | Description |

4. **LinkedIn social selling** — Video comments, connection request videos, Sales Navigator outreach.
5. **Customer onboarding** — Video walkthroughs for new clients.
6. **Video testimonials** — Capture and publish client success stories.

| OS Layer | Dubb Role |
|----------|-----------|
