# Onyx

**What it is:** Open-source enterprise AI platform combining chat, search, and custom AI agents. Connects to internal knowledge via 45+ permission-aware connectors. Self-hostable, air-gapped capable, SOC 2 Type II certified. 20k GitHub stars. Deployed in ITAR, CMMC, FERPA, GDPR, and FedRAMP-regulated environments.

> *"Onyx is your team's entry point to Generative AI, offering a natural language interface for any LLM while integrating seamlessly with your knowledge and applications."*

**Source:** docs.onyx.app | onyx.app/solutions/secure-ai

## Core Features

| Feature | Description |
|---------|-------------|
| **Enterprise Search** | Deep learning models + advanced RAG + multi-pass indexing + contextual retrieval + LLM-based knowledge graphs. Searches across all connected data sources and returns cited answers or Deep Research reports. |
| **AI Chat** | Conversational AI connected to internal data, web search, and tools. Supports any LLM (OpenAI, Anthropic, Azure, Bedrock, or local open-weight models). |
| **Custom AI Agents** | Create purpose-built agents with custom instructions, knowledge, and actions. Tag-able Slack bots per workflow. MCP and OpenAPI actions. |
| **Code Execution** | Execute code directly in chat sessions. |
| **Image Generation** | Built-in image generation. |
| **Voice Mode** | Voice interface. |
| **Web Search** | Enrich LLM knowledge with real-time internet search. |
| **MCP Server** | Onyx acts as an MCP server — exposes tools to other AI clients. |

## Connectors (45+)

Connectors sync data **and** ACLs (document-level permissions). Key list:

| Category | Connectors |
|----------|-----------|
| **Collaboration** | Slack, Microsoft Teams, Notion, Confluence, SharePoint, Google Drive, Dropbox |
| **CRM/Sales** | Salesforce, HubSpot, Zendesk |
| **Development** | GitHub, Jira |
| **Communication** | Gmail |
| **+ 30 more** | + e.g. Asana, Airtable, Box, Egnyte, S3-compatible storage, custom connectors |

> Permission sync is **real-time** — when access changes in SharePoint/Confluence/Google Drive, Onyx reflects it within minutes. No stale permissions, no manual re-indexing.

## Governance & Security

| Capability | Details |
|-----------|---------|
| **RBAC** | Per-user and per-group rate limits, connector access restrictions, usage policies |
| **SCIM + IdP** | Provision users/groups from Okta, Azure AD, or any SAML/OIDC provider |
| **Audit Trail** | Full query/response audit trail on every interaction |
| **Model Control** | Approve specific models per team or use case; swap providers without disrupting users |
| **Usage Analytics** | Query logs, feedback tracking, ROI measurement, adoption gaps |
| **Shadow AI Blocker** | One approved AI front door — users stop pasting company data into ChatGPT |
