## Purpose

Canonical implementation source for the **Veritas Capital Relationship OS** on the existing `Ksdeng1559/atomic-crm` fork. Converts the capital-relationship PRD into buildable data, workflow, UI, automation and AI requirements.

## One-line operating loop

**Capital Discovery → Relationship Intelligence → Qualification → Project Matching → Due Diligence → Commitment → Funding → Reporting → Reinvestment → Referral**

## The 4 questions it answers

1. Who are the most important capital relationships for Veritas?
2. Which project is each relationship best matched to?
3. What is the status of the capital pathway?
4. What is the next action, owner and due date?

## Architecture Decision (2026-10-08, Dennis approval)

Implement by extending the existing Atomic CRM fork rather than creating a new CRM.

- **Repository:** `Ksdeng1559/atomic-crm`
- **Multi-tenant:** Veritas runs as a second organization inside the shared Atomic CRM Supabase project, using Clerk Organizations
- **Staging:** Build and test first in a separate staging Supabase project in a new account. Merge into shared project only after isolation tests pass.
- **Migration principle:** Atomic-first. Frappe designs are legacy references only.

## Product North Star

**Investor Lifetime Capital (ILC)** = capital already invested + probable future allocations + weighted referral capital. Internal metric, not a security or commitment.

**Supporting KPIs (10):** Capital Relationship Coverage, Weighted Capital Pipeline, Repeat Investor Rate, Introduction Rate, COI Capital Influence, Average Allocation, Project Match Coverage, Stalled Relationship Rate, Qualified-to-Committed Conversion, Reinvestment Rate.

## Scoring Engine

**Project Match Score V1:** 20% Asset Fit + 10% Geography Fit + 15% Risk Fit + 15% Structure Fit + 10% Hold Fit + 15% Capital Fit + 15% Relationship Strength
- 80–100: Excellent Match
- 65–79: Strong Match
- 50–64: Possible Match
- <50: Do Not Prioritize

**Capital Capacity Score:** 30% Typical check + 20% Available capital + 15% Private market exp + 20% Historical allocation + 15% Repeat capacity. (All scores also store confidence level.)

**Relationship Score:** 20 Trusted intro + 20 Sponsor relationship + 15 Meeting engagement + 10 Historical interactions + 10 Data room engagement + 15 Past investments + 10 Introductions made.

## Human Override Rule

Every AI score must support:
- `machine_score`
- `human_override`
- `human_override_reason`
- `final_score`

Override and reason retained for audit + model tuning.

## Mandatory Next Action Rule

Every Strategic LP, Family Office, Emerging Strategic LP, Active COI, JV Partner must have:
- next action, action owner, due date, reason, expected outcome

Dashboard rule: IF strategic_relationship = true AND no open task exists THEN flag RELATIONSHIP_STALLED.

## Capital Relationship Coverage Formula

`Qualified Capital Universe ÷ 12-Month Forecast Equity Requirement`

- Above 4× → Healthy
- 2× to 4× → Monitor
- Below 2× → Capital Development Priority

(Thresholds configuration-driven.)

## AI / Agent Requirements

| Agent | Input | Output |
|---|---|---|
| Investor Research | `contact_id` | Business background, public investment history, possible conversation topics, source URLs. All unverified until human review. |
| Meeting Intelligence | Meeting transcript/notes | Investment preferences, check size, concerns, timeline, decision process, next action. UI: AI Suggested Updates → Accept/Edit/Reject. |
| Capital Match | Project | Investor, fit score, explanation, missing data, suggested next action. |
| Daily Capital Briefing | Active raises | "What are the most important capital actions today?" |
| Relationship Watch | Open relationships | Identify stale + no follow-up. Create suggested task only — do NOT autonomously contact. |

## Workflow Automations

- Discovery Meeting Completed → Meeting Intelligence → Suggested CRM Updates → Human Approval → Investor Profile Updated → Recalculate Matches → Create Next Action
- New Project Created → define attributes → run match engine → return top relationships → relationship owner review → approved outreach queue
- New Introduction → match/create contact → attach introducer → record relationship strength → generate research brief → create discovery task
- Reinvestment → existing investor + new opportunity → calculate reinvestment candidate → human review → next action
- Referral → positive milestone → suggest referral opportunity → owner approves timing → track referral request, introductions, influenced capital

## Compliance & Governance Guardrails

**CRM MAY:** store accreditation/eligibility, track KYC/AML, record document approvals, preserve audit history, track communication + diligence state.

**CRM and AI agents MUST NOT independently:** decide accredited investor status, modify offering terms, promise returns, send unapproved solicitation, generate final legal offering documents without professional review, negotiate final securities terms autonomously.

Legal, securities, tax and licensing requirements implemented per project counsel and applicable jurisdiction.

## RLS Roles

admin / capital_manager / sponsor / advisor / operations / read_only

Restricted: investor verification, KYC/AML, legal documents, banking/funding instructions. RLS enforces least-privilege.

## Implementation Phases (4)

1. **MVP Data + Core UI** — investor profiles, preferences, projects, attributes, capital stacks, allocations, project matching, expanded pipeline, mandatory next action, Capital Dashboard V2. MVP question: "Who are the 25 most important capital relationships and what should Veritas do with each one next?"
2. **Relationship Intelligence** — introductions, COI profiles, relationship graph, investor question library, research briefs, Meeting Intelligence, Relationship Watch, match explanations.
3. **Capital Execution** — investor data room, document events, subscription workflow, verification, e-signature, capital allocation tracking, audit trail.
4. **Capital Intelligence** — ILC analytics, predictive matching, reinvestment models, COI performance, capital coverage forecasting, feedback learning from `match_outcomes`.

2. **UI** — Investor Profile, Project Profile, Capital Dashboard, Match View
3. **Workflow** — pipeline, next-action enforcement, introductions/COI, task automation
4. **AI** — Research Agent, Meeting Intelligence, Matching Agent, Daily MIT briefing
5. **Governance** — audit log, document controls, human approval flows, permission testing, QA

## Acceptance Criteria (10)

1. Open dashboard → see target, soft-circle, committed, funded, weighted pipeline, capital gap
2. Open investor → see complete profile, source/introduction, preferences, capacity, project matches, next action
3. Open project → see capital stack, investor matches, current pipeline, capital gap
4. Identify all strategic relationships without an open next action
5. Record soft circles, commitments, funded allocations without conflating them
6. Run deterministic V1 matching formula, see explanation for each match
7. Override AI score with reason, preserve machine score
8. Restrict sensitive compliance data through RLS
9. Maintain audit trail for material capital, verification, stage changes
10. Use MCP/AI tools under authenticated user's permissions (not bypassing RLS)
