## Strategic position (verbatim from Notion spec)

> "Veritas does not speculate on dirt. Veritas manufactures development certainty."

The paper must explain how Veritas converts uncertainty (land, entitlement, infrastructure, capital, buyer demand) into documented evidence and staged investment decisions.

## Claim class discipline (per Notion §"Knowledge Discipline")

Every claim that lands in the paper must be tagged to one of these 8 classes:

| Class | Tag | Treatment in draft |
|---|---|---|
| Verified Fact | `[FACT-V]` | Cite inline; full source in bibliography |
| Sponsor-Provided Fact | `[FACT-S]` | Cite inline; flagged as sponsor-sourced |
| Underwriting Assumption | `[ASSUMP]` | Disclose; show base / upside / downside / severe downside |
| Projection | `[PROJ]` | Disclose horizon + sensitivity; no certainty language |
| Draft | `[DRAFT]` | Internal only; never public |
| Approved External Claim | `[CLAIM-A]` | Cite source + Veritas approval on file |
| Confidential | `[CONF]` | Do not include in paper; deal-room only |
| Superseded | `[SUPERSEDED]` | Do not include; reference superseded-by doc |

**Non-negotiable rule (per Notion):** No agent should treat an underwriting assumption as a verified fact.

## Source-record schema (every claim gets one)

| Field | Description |
|---|---|
| Claim ID | `WP1-C###` (auto) |
| Proposed claim | Quoted text intended for the draft |
| Claim class | One of the 8 above |
| Source (URL) | Public link or internal doc path |
| Publisher | Source organization / Veritas project |
| Publication date | YYYY-MM-DD |
| Data period | What the source measures (e.g., "2024 ACS 5-year estimates") |
| Retrieval date | YYYY-MM-DD |
| Geography | Exact metro / county / submarket |
| Methodology | How the figure is calculated (units, base, weighting) |
| Confidence | H / M / L + reason |
| Section # | Which of the 14 sections the claim lands in |
| Reviewer | David / Daniel / specialist / n/a |
| Status | unverified / supported / disputed / revised / removed |

**Confidence rubric:**
- **H** = primary government / municipal / Veritas internal contract / data ≤ 12 months old
- **M** = brokerage / appraisal / industry research with disclosed methodology; or data 12-36 months old
- **L** = aggregator, business media context, or data > 36 months old → must be upgraded or removed

## OPEN ITEM handling

If a claim cannot be sourced to the required level:

- **Never** fill the gap with an assumption, projection, or projection-style language
- Mark the claim slot in the draft as `**[OPEN ITEM: <what is needed>]**`
- Add a row to the claim register with Status = `open`
- List all OPEN ITEMs in the reviewer change log
- The OPEN ITEM blocks that section from publication until resolved

## Section-by-section research plan (14 sections)

For each required section, the research plan defines: (a) the question the section must answer, (b) what facts are needed, (c) the primary source lanes, (d) what would block the section (OPEN ITEM triggers).

### §1 Executive summary + investment thesis
- **Question:** What is the one-sentence thesis + the 3-5 evidence points that back it?
- **Needed:** (1) Veritas Business Plan 2026 — investment thesis section. (2) Investor Mind Map top claims. (3) One verified market datapoint (e.g., KC industrial vacancy H1 2025). (4) One Veritas project datapoint (e.g., "X acres under control in Y submarket").
- **Lanes:** A, C, D
- **Blockers:** No Veritas Business Plan 2026 on file in wiki → must be added or referenced from Notion by Dennis.

### §2 The development uncertainty problem
- **Question:** Why is "buying dirt and hoping" the failure mode?
- **Needed:** (1) At least 3 named real failure modes with cited source (NAHB / academic / institutional). (2) One KC / Lee's Summit-specific illustration if available.
- **Lanes:** F, D
- **Blockers:** If no academic / institutional source available, must use Veritas own underwriting track record (with `[FACT-S]` tag) — never invented.

### §3 Why raw acreage is not automatically an investment
- **Question:** What is the gap between "appraised value" and "investment-grade certainty"?
- **Needed:** (1) Appraiser / institutional definition of "investment-grade" (e.g., Appraisal Institute). (2) Kansas / Missouri property tax / carrying cost data. (3) Auction / failed-platting case study if available.
- **Lanes:** E, C, F
- **Blockers:** If no case study available, this section is conceptual only — no fabricated example.

### §4 Green Acres: Buy → Convert → De-Risk → Monetize
- **Question:** How does Veritas describe the four-step operating model?
- **Needed:** Veritas internal — Business Plan 2026 + Veritas Investor Mind Map. No external claim should be made about the four-step model.
- **Lanes:** A
- **Blockers:** Source doc must be on file in `drafts/business-plan-2026/` before drafting.

### §5 Control before ownership
- **Question:** What are the legal control instruments (purchase contract, option, LOI, joint venture, easement)?
- **Needed:** (1) Legal definitions — must come from a licensed attorney review (Notion specialist trigger). (2) One or more KC / Missouri jurisdictional notes (statute, local case).
- **Lanes:** A, J (attorney)
- **Blockers:** Section CANNOT be drafted without attorney review; the language is securities-sensitive.

### §6 Residual land-value underwriting
- **Question:** What is the residual method and what inputs make it defensible?
- **Needed:** (1) Appraisal Institute / ULI reference for residual method. (2) Inputs must be project-specific (NOT generic). (3) Project example MUST be either (a) labeled hypothetical or (b) backed by Veritas project data with `[FACT-S]` tag.
- **Lanes:** E, F, A
- **Blockers:** No generic national averages used as project examples. Per Notion §13, every example must be clearly labeled hypothetical unless project evidence is verified.

### §7 Seven-stage parcel lifecycle
- **Question:** What are the seven stages and what evidence is required at each handoff?
- **Needed:** Veritas internal — Business Plan 2026 + project plans. Stages to be defined in claim register (likely: Control → Diligence → Fatal-Flaw Check → Municipal Signal → Application → Entitlement/Close → Horizontal NTP).
- **Lanes:** A, B
- **Blockers:** If Business Plan 2026 has not been committed to wiki, the seven-stage list is a Veritas internal claim and must be source-locked.

### §8 Six evidence-based investment gates
- **Question:** What gates must capital clear before the next tranche?
- **Needed:** Veritas internal — 6-gate model from Business Plan 2026. Per Notion §"Paper 3 Brief", gates: Control → Fatal Flaws → Municipal Signal → Application → Entitlement/Close → Horizontal NTP. Each gate requires a documented pass/fail criterion.
- **Lanes:** A
- **Blockers:** Without Business Plan 2026, the 6-gate model is unsourceable. STOP.

### §9 Demand-led design + buyer evidence
- **Question:** How does Veritas evidence demand before vertical construction?
- **Needed:** (1) Veritas internal — buyer LOIs, builder agreements, market studies. (2) Brokerage market evidence for KC / Lee's Summit. (3) Demographic + employment trend data.
- **Lanes:** A, D, C
- **Blockers:** If no Veritas buyer LOIs on file, demand section is illustrative only.

### §10 Entitled, shovel-ready, finished-pad exits
- **Question:** What is the difference between the three exit stages and who buys at each?
- **Needed:** (1) Veritas internal — exit criteria for each stage. (2) Market evidence for buyer classes (builders for finished lots, REITs for SFR rentals, etc.). (3) KC / Lee's Summit absorption data.
- **Lanes:** A, D, C
- **Blockers:** Must use named builder / REIT buyer classes with sourced demand, not invented.

### §11 Capital-at-risk ladder + staged capitalization
- **Question:** How does staged cap protect downside?
- **Needed:** (1) Veritas internal — staged capitalization model. (2) Reference to general PE / real estate fund staged-cap literature (PERE, ULI). (3) Project example required.
- **Lanes:** A, F, A
- **Blockers:** No project example = section is conceptual only.

### §12 Risks, stress tests, walk-away discipline
- **Question:** What are the 5+ stresses the paper will model, and what triggers a walk-away?
- **Needed:** Per Notion §"Paper 3 Brief": 12- and 24-month delays; 10% and 20% cost overruns; density / saleable-yield loss; lower pricing + slower absorption; reduced debt proceeds + higher capital costs. Each stress needs (a) a metric, (b) a Veritas walk-away criterion.
- **Lanes:** A, F
- **Blockers:** Walk-away thresholds are Veritas-internal and must be on file.

### §13 Example — labeled hypothetical unless project evidence verified
- **Question:** Is there a real Veritas project with sufficient verified data to use as the worked example?
- **Decision rule (per Notion §13):** Default = clearly labeled hypothetical. Real project only if (a) all underwriting assumptions are disclosed, (b) David + Daniel approve, (c) no confidentiality breach.
- **Lanes:** A
- **Blockers:** Cannot use a real project without David + Daniel joint approval.

### §14 Veritas positioning + next-step invitation
- **Question:** What CTA closes the paper without crossing the securities line?
- **Needed:** (1) Veritas positioning language (approved by David + Daniel). (2) CTA must NOT include offering terms, target returns, accreditation claims, or any language that could be construed as general solicitation. (3) CTA must route to a relationship conversation, not a subscription.
- **Lanes:** A, J (attorney)
- **Blockers:** Section CANNOT be drafted without attorney sign-off on CTA language. Per Notion §"Compliance Boundary", regulated actions are human-controlled.
