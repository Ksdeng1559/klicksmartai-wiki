# Whatcom County, WA — Spectra Project Workspace

## Purpose

This folder is the live project workspace for Spectra Holdings' Whatcom County, Washington housing, CDFI, MCF, and community development pilot.

It consolidates county intelligence, Census data, housing sentiment, capital strategy, partner alignment, and execution tasks into one operating folder.

# Current Strategic Thesis

Whatcom County is a strong candidate for Spectra's first CDFI / MCF / CLT housing pilot because it combines:

- measurable housing need,
- documented affordability gap,
- active public-sector housing support,
- potential CLT partnership infrastructure,
- strong fit for mission-aligned capital,
- and a regulatory timing window through missing-middle housing policy.

The project should proceed from intelligence into validation and modeling before any final investment decision.
