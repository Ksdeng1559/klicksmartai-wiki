## Construction / development

| Term | Meaning | Source |
|---|---|---|
| **GC** | General contractor — the lead contractor on a construction project | Project context |
| **GC/CI** | General contractor / construction-included (all-in contract type) | Common industry |
| **CO** | Certificate of Occupancy — issued by the city when a building is ready to occupy | Project context |
| **Pre-development** | Phase before construction starts (entitlement, design, permits, financing) | Industry |
| **Multifamily** | Residential buildings with multiple units (apartments, townhouses, condos) | Project context — primary focus |
| **Mid-rise** | 5-12 story residential building | Industry |
| **Low-rise** | 1-4 story residential building | Industry |
| **Infill** | New construction on a previously-developed lot | Industry |
| **Custom home** | Single-family home built to owner specs (GPC secondary focus) | Project context |
| **Sponsor** | The equity investor / developer on a real estate project | RE finance |
