## Core Entities

### Person
Individual contact — name, title, organization, email, LinkedIn, role, pain signals.

### Organization
Company or firm — name, type, location, website, AUM/revenue, verticals served, pipeline stage.

### Relationship
Edge between Person A and Person B — type (knows, works_with, introduced, advises, etc.), strength score, last_interaction, context.

### Signal
External trigger event — type, source, timestamp, target_person, target_org, urgency_score, vertical_relevance.

### Opportunity
*Generated by Mission Control — a scored, ranked opportunity pulled from graph pattern analysis.*

| Field | Type | Description |
|-------|------|-------------|
| `opportunity_id` | string | Unique identifier |
| `name` | string | Opportunity name (entity or event-driven) |
| `source_entity` | string | Primary entity the opportunity is attached to |
| `source_signals` | string[] | Signals that triggered this opportunity |
| `sip_vertical` | enum | mortgage, insurance, wealth |
| `score` | number | 0–100, composite opportunity score |
| `urgency` | enum | hot, warm, cold |
| `pattern_type` | enum | co-occurrence, temporal, relational, behavioral, anomaly |
| `linked_lead` | Lead | ClientFlow lead (if applicable) |
| `linked_subscriber` | Subscriber | MIX deal (if applicable) |
| `recommended_action` | string | Next best action (e.g. "route to advisor", "generate battlecard") |
| `gtm_play` | string | GTM play selected by Mission Control (e.g. "ABM with intent data") |
| `confidence` | number | 0–1, confidence in pattern validity |
| `generated_at` | timestamp | When Mission Control generated this opportunity |
| `status` | enum | open, actioned, closed-won, closed-lost, stale |
| `outcome` | string | Result once closed (for learning layer feedback) |

### Mission Control
*RIOS's opportunity engine + GTM autopilot + self-correcting loop.*

| Field | Type | Description |
|-------|------|-------------|
| `mission_control_id` | string | Always `mission-control` (singleton) |
| `goal_ref` | string | Path to `/goal` north star document |
| `active_plays` | string[] | Currently active GTM plays |
| `pattern_weights` | object | Per-pattern-type weighting (co-occurrence, temporal, etc.) |
| `score_threshold` | number | Opportunity score cutoff for GTM activation (default 70) |
| `self_correction_enabled` | boolean | Whether self-correction loop is active |
| `last_correction` | timestamp | Last self-correction event |
| `correction_log` | object[] | Log of self-corrections: { timestamp, trigger, adjustment, outcome_delta } |
| `scan_interval` | string | How often Mission Control scans the graph (e.g. "15m") |
| `status` | enum | active, paused, recalibrating |

**Self-correction log fields:** `{ trigger, adjustment, pattern_hit_rate_before, pattern_hit_rate_after, goal_delta }`

### Battlecard
Actionable intelligence output — generated from opportunity + signal + relationship graph. See `rios/battlecard-schema.md`.

### Meeting
Scheduled or completed interaction — attendees, outcome, follow_up_required, linked_opportunity.

### Policy
Regulatory or compliance rule — jurisdiction, vertical applicability, language constraints, risk_level.

### Funding Source
Grant, SBIR, CDFI, government program — agency, deadline, eligibility, fit_score, linked_opportunities.

## ClientFlow Entities

### Lead
Qualified prospect captured via ClientFlow intake.

| Field | Type | Description |
|-------|------|-------------|
| `lead_id` | string | Unique identifier |
| `name` | string | Full name |
| `firm` | string | Company / practice name |
| `email` | string | Contact email |
| `phone` | string | Contact phone |
| `vertical` | enum | mortgage / insurance / wealth |
| `practice_area` | string | e.g. "estate planning", "refinance", "commercial" |
| `aum_target` | number | AUM or revenue target (if disclosed) |
| `years_experience` | number | Practitioner experience |
| `client_profile` | string | Target client type served |
| `qualification_score` | number | 0–100% match score |
| `routing_decision` | string | Advisor assignment recommendation |
| `intake_completed_at` | timestamp | When90-second intake finished |
| `assigned_advisor` | string | Advisor ID (from `assigned_to`) |
| `status` | enum | todo / progress / review / blocked / done |
| `source` | string | Where the lead originated |
| `battlecard_id` | string | Linked RIOS battlecard (if generated) |

**Trigger:** Battlecard auto-generated when `qualification_score >= 70%`.

---

### Advisor
Financial professional assigned to leads.

| Field | Type | Description |
|-------|------|-------------|
| `advisor_id` | string | Unique identifier |
| `name` | string | Full name |
| `vertical` | enum | mortgage / insurance / wealth |
| `specialties` | array | Practice areas covered |
| `capacity` | number | Max concurrent leads |
| `current_load` | number | Active leads currently assigned |
| `available_capacity` | number | capacity - current_load |
| `contact` | object | email, phone, LinkedIn |
| `status` | enum | active / busy / unavailable |

**Load balancing:** RIOS routes new leads to advisor with highest `available_capacity` in matching vertical.

---

### IntakeSession
90-second qualification conversation.

| Field | Type | Description |
|-------|------|-------------|
| `session_id` | string | Unique identifier |
| `lead_id` | string | Linked lead |
| `started_at` | timestamp | Session start time |
| `completed_at` | timestamp | Session end time |
| `questions_answered` | number | Count of questions responded to |
| `qualification_score` | number | Computed score (0–100%) |
| `routing_decision` | object | { advisor_id, vertical, practice_area } |
| `output_payload` | object | Full qualification result for battlecard generation |

**Output:** Feeds directly into RIOS battlecard generation pipeline.

## MIX Dashboard Entities

### Subscriber
Open deal in the MIX pipeline — analogous to a `Lead` that has entered active pipeline management.

| Field | Type | Description |
|-------|------|-------------|
| `subscriber_id` | string | Unique identifier |
| `name` | string | Deal / lead name |
| `icon` | string | Emoji icon (🏠 🏗️ 📋 etc.) |
| `status` | enum | todo / progress / review / blocked / done |
| `assignee` | string | Person ID (from SEED_PEOPLE) |
| `due` | string | Due date (display string) |
| `priority` | enum | High / Med / Low |
| `updated` | timestamp | Last modification time |
| `linked_lead_id` | string | Cross-reference to ClientFlow Lead |
| `linked_opportunity_id` | string | Cross-reference to RIOS Opportunity |

**MIX ↔ SIP State Mapping:**

| SIP State | MIX Status | Description |
|-----------|-----------|-------------|
| NEW_LEAD | `todo` | Signal detected, not yet engaged |
| ENGAGED | `progress` | 2+ opens, 1+ click, or LinkedIn view |
| CURIOUS | `review` | Replied with question |
| OBJECTION | `blocked` | Price/timing/competitor objection |
| READY | `review` | Expressed booking interest |
| NURTURE | `todo` | 30 days no engagement |
| REMOVED | `done` | Unsubscribe — permanent suppression |

## Cross-Entity Relationships

```
Signal
 → triggers → Lead (via intake)
  → triggers → Opportunity

Lead
  → assigned_to → Advisor
  → intake_of → IntakeSession
  → qualified_from → IntakeSession
  → generates → Battlecard
  → maps_to → Subscriber (MIX)
  → linked_to → Opportunity

IntakeSession
  → qualifies → Lead
  → outputs → routing_decision

Subscriber (MIX)
  ← maps_from ← Lead
  → linked_to → Opportunity
 → tracked_by → MIX Dashboard

Advisor
  ← assigned_to ← Lead
  ← manages ← Subscriber

Opportunity
  ← generated_by ← Mission Control
  ← linked_to ← Lead
  ← linked_to ← Subscriber
  → generates → Battlecard
  → updates → Meeting

Mission Control
  → scans → Signal
  → scans → Relationship
  → scans → Lead
  → scans → Subscriber
  → generates → Opportunity
  → triggers → Battlecard
  → recommends → Advisor
  → alerts → Anomaly
```

## Score Computation

| Score | Source | Used For |
|-------|--------|---------|
| `qualification_score` | ClientFlow intake engine | Lead routing, battlecard trigger |
| `opportunity_score` | RIOS graph + signal urgency | Battlecard priority ranking |
| `relationship_score` | Graphify known_connections | Warm intro path detection |
| `urgency_score` | Signal type + event recency | Battlecard "why now" framing |
| `overall_priority` | Weighted composite | MIX Dashboard sort order |
| `available_capacity` | Advisor current_load | Load-balanced routing |
