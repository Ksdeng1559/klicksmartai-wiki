# SBIR/STTR Intelligence Layer

The SBIR/STTR Intelligence Layer supports non-dilutive innovation funding discovery, qualification, proposal development, and commercialization strategy.

## Purpose

Match company technology, county needs, tribal priorities, and federal agency solicitations to SBIR/STTR opportunities.

```text
Company Technology
→ Agency Need
→ Solicitation Topic
→ Prior Award Pattern
→ Proposal Strategy
→ Commercialization Path
```

## Core Use Cases

- Match Spectra, Tiyo, and MineTeck capabilities to active SBIR/STTR solicitations
- Track Phase I, Phase II, and Phase III award patterns
- Analyze prior awardees and agency funding preferences
- Identify agency technical priorities
- Generate proposal outlines and commercialization plans
- Connect SBIR/STTR opportunities to county, tribal, and infrastructure needs

## Reference Repositories

### trustdan/awesome-sbir-sttr

Use as a source map for agency portals, SBIR/STTR education, and federal opportunity links.

### USCTIE/SBIR-STTR-data

Use as a data pipeline reference for historical SBIR/STTR awards, FPDS records, SBIR.gov crawling, fuzzy matching, and Phase I/II/III pattern analysis.

### cory-garms/proposal-pilot

Use as an application architecture reference for RAG-based proposal automation, solicitation scraping, capability scoring, and Technical Volume / Commercialization Plan generation.

## RIOS Role

SBIR signals feed RIOS as opportunity records. RIOS connects each opportunity to people, organizations, funding sources, relationship paths, and next-best actions.
