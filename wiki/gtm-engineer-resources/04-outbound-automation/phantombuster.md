## At a Glance

**"Cloud-based multichannel automation — collect lead data and automate actions across LinkedIn, Instagram, Twitter/X, and more."**

Phantombuster is a cloud-based automation tool for social media scraping and outreach. Pre-built "Phantoms" for each platform. Cookie-based automation (less stable than API-based tools). 14-day free trial with no credit card required.

**Key differentiator:** Multichannel automation in one platform. Broad platform coverage (LinkedIn + Instagram + Twitter + Facebook + GitHub).

## GTM Engineering Fit

### Pipeline Position
- **Multichannel outreach + data extraction:** Use for LinkedIn automation (connection requests, DMs) and social data extraction
- **Warning:** Cookie-based — LinkedIn blocks these regularly. Not as stable as API-based tools or purpose-built platforms
- **Best for:** Bulk LinkedIn connection requests + social listening on a budget

### Spectra Holdings Use Case
- Extract LinkedIn profiles for CDFI contacts in target counties
- Run LinkedIn connection request campaigns to missionary org decision-makers
- Monitor Twitter/X for faith-based org announcements
