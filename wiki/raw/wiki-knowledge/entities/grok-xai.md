# xAI Grok — WebSearch & DeepSearch

**Company:** xAI (Elon Musk)
**Launched:** February 2025 (Grok 3)
**Context Window:** 128k tokens
**Mission:** Help users understand the universe — combining pre-trained knowledge with real-time web data

---

## Two Search Products

### Grok WebSearch — Fast, Contextual Retrieval

| Feature | Detail |
|---------|--------|
| Index size | 14M+ pages |
| Index type | Hybrid — inverted keyword + vector semantic |
| Real-time | Index-only (no live crawl on demand) |
| Query trigger | Automatic — no explicit command needed |
| Response speed | Fast (bounded by index freshness) |

**Architecture note:** Index-only model (like Bing/Google static index) vs. live web access. Faster but bounded by index freshness.

---

### Grok DeepSearch — Complex Research & Reasoning

| Feature | Detail |
|---------|--------|
| Crawling | Two-tier: continuous indexing + on-demand query-driven crawl |
| Reasoning | Chain-of-thought (ReAct framework) |
| Verification | Cross-checks up to 7 levels of sources |
| Transparency | Visible reasoning trace — users see source selection, evidence eval, logic steps |
| Max tool calls | 10 per query |
| Min before answer | 3 function calls |

**Process for complex queries:**
1. Breaks query into sub-queries
2. Fetches relevant pages in real-time
3. Follows links to deepen understanding
4. Cross-verifies across multiple sources
5. Synthesizes coherent answer with cited reasoning

**Praise:** Garry Tan (Y Combinator) cited its transparency as a standout feature.

## Competitive Position

| Dimension | Grok WebSearch | Grok DeepSearch | Tavily | Exa |
|-----------|---------------|-----------------|--------|-----|
| Index size | 14M+ pages | Dynamic crawl | Deep indexing | Financial/academic focus |
| Reasoning trace | No | Yes | Partial | No |
| Real-time crawl | No (index-only) | Yes | Yes | Yes |
| Semantic understanding | Yes (vector index) | Yes | Yes | Yes |
| Transparency | Low | High | Medium | Medium |
| Free tier | Limited | Limited | Yes | Yes |

## Key Takeaways for KlickSmartAI Research Pipeline

1. **DeepSearch reasoning trace** is a differentiator —chain-of-thought visible to users. Tavily Research and Exa don't expose this level of reasoning transparency.
2. **Index-only WebSearch** is fast but bounded. Hermes Agent's approach (live crawl via Firecrawl + multi-engine search) may be more current for specialized verticals.
3. **Grok's X/Twitter integration** is native — analyzing X user profiles and posts is built-in. Relevant if Twitter/X signals are ever added to the research stack.
4. **xAI is competing directly with Perplexity** on the AI search front — DeepSearch's visible reasoning is a direct feature parity play.
