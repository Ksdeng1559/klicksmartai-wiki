# Mailgun — Transactional Email API

## What It Is

Transactional email API service for developers. Used for sending automated emails: notifications, alerts, onboarding sequences, order confirmations, etc.

## Use Cases for KlickSmartAI

| Use Case | Why Mailgun |
|----------|------------|
| Client onboarding emails | Automated welcome + next steps sequence |
| Course delivery | Send access links, module notifications |
| Invoice delivery | Automated invoice emails to clients |
| AI alert notifications | Hermes daily briefings via email |
| Marketing (with caveat) | Transactional only — not bulk marketing |

## Notes

- Transactional email = triggered, one-to-one emails (quotes, invoices, confirmations)
- Not a bulk marketing platform
- Check pricing tiers when configuring for client work
- Alternative: SendGrid (for comparison)
