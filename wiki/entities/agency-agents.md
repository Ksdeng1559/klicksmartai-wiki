# Agency Agents (GitHub Project)
URL: https://github.com/msitarzewski/agency-agents
Type: Multi-Agent Framework / Agent Library

## Overview
A comprehensive collection of specialized AI agents designed as a complete AI agency. The project focuses on creating agents with distinct personalities, processes, and proven deliverables across various Divisions (e.g., Academic, Design, Finance, Sales).

## Key Features
- **Division-Based Architecture:** Agents are grouped by specialty (e.g., Academic Division includes Anthropologist, Geographer, Historian, etc.).
- **OpenClaw Integration:** Recent updates include integration with OpenClaw, converting agency-agent definitions into SOUL.md (persona) and AGENTS.md (operations) formats.
- **Persona-Driven:** Each agent is defined with a specific vibe, emoji, and set of services, moving beyond simple prompt-engineering to full identity design.
- **Operational Rigor:** Emphasizes proven deliverables and specific processes for each expert agent.

## Relevance to KlickSmartAI OS
- **Squad Model:** Mirrors the Agent Squad (Monica, Dwight, Kelly, etc.) orchestration.
- **Identity Design:** Provides a reference for implementing vibe and identity layers in agent personas.
- **Integration Patterns:** The conversion logic from raw agent definitions to operational files (SOUL.md) is a relevant pattern for our own skill deployment.
