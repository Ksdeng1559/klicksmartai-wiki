# Chatwoot

**What it is:** Open-source customer support platform — alternative to Intercom and Zendesk
**URL:** https://www.chatwoot.com/
**Stars:** 25K+ GitHub | **Businesses:** 15,000+
**License:** Open source (MIT) | **Deployment:** Self-hosted or cloud

---

## Core Features

### AI Layer (Captain)
- **AI Agent** — learns from help center, chats, FAQs to answer common questions automatically
- **Copilot** — smart answer suggestions for agents, past conversation lookups, help article search
- **Translation** — responds in customer's native language
- **Contact pre-fill** — email, phone pulled into chat widget

### Omnichannel Support
- Website live chat (customizable widget)
- Email
- Facebook, Instagram
- Telegram, LINE
- WhatsApp
- **Unified inbox** — all channels in one place

### Knowledge Base
- Help Center with AI-powered search
- Multiple portals (per brand/product)
- Custom domain with auto-SSL
- Content by category
- 24x7 self-service for customers

### Integrations
- REST API for custom extensions
- Webhooks
- 400+ contributors on GitHub

### Security
- Open source (host on your own server)
- SOC 2 Type II compliant (cloud)
- Self-hosted = own your customer data
