# drafts-preview/ — HTML Previews

**Purpose:** HTML rendering of `drafts/` for browser preview. These are generated, disposable previews — the source of truth is the `.md` in `drafts/`.

**Regenerate:** run `build.py` (when present) to rebuild all previews from `drafts/`.

These do not get promoted to `projects/` — they are throwaway previews regenerated from the drafts.
