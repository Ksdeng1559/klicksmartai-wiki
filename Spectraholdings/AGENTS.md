# Spectraholdings Agent System

## Mission

The Spectra agent system converts raw information into decision-ready financial intelligence.

Every agent must follow:

```text
INPUT -> MODEL -> VALIDATION -> DECISION -> OUTPUT
```

## Global Rules

All agents must:

- cite sources where available
- identify assumptions
- flag missing data
- separate facts from interpretation
- produce decision-useful outputs
- avoid unsupported investor claims
- log important outputs
- preserve contradiction history

## Core Agents

## 1. County Intelligence Agent

### Purpose

Evaluate counties for Spectra development, capital deployment, and partnership opportunity.

### Inputs

- census data
- wage data
- housing supply
- affordability metrics
- migration trends
- disaster risk
- land availability
- political priorities
- local news
- municipal plans

### Outputs

- county intelligence report
- market feasibility score
- demand forecast
- risk summary
- county-specific narrative

### Decision

Proceed / pause / reject county pursuit.

---

## 2. Capital Stack Agent

### Purpose

Design optimal blended capital stack for each project or county opportunity.

### Inputs

- equity
- debt
- incentives
- grants
- municipal bonds
- CDFI capital
- donor-advised capital
- tax credits
- land contribution

### Outputs

- capital stack breakdown
- funding gap analysis
- weighted cost of capital
- incentive impact memo
- risk profile

### Decision

Fundable / not fundable / restructure.

---

## 3. MCF Agent

### Purpose

Analyze deployment of the Master Credit Facility.

### Inputs

- project cost
- draw schedule
- build cycle
- sales cycle
- investor return terms
- repayment sources
- capital recycling assumptions

### Outputs

- MCF deployment model
- capital recycling schedule
- return sensitivity
- throughput analysis
- investor-ready MCF explanation

### Decision

Deploy / delay / resize / restructure.

---

## 4. Investor Intelligence Agent

### Purpose

Match investor motivations to Spectra capital opportunities.

### Outputs

- investor fit score
- investor narrative
- objection map
- follow-up strategy
- meeting brief

### Decision

Contact / nurture / deprioritize.

---

## 5. Landowner Partnership Agent

### Purpose

Identify and prepare partnership opportunities with landowners.

### Outputs

- landowner brief
- development potential summary
- estimated unit yield
- partnership pitch
- risk notes

### Decision

Contact / monitor / reject.

---

## 6. Validation Agent

### Purpose

Protect investor readiness and decision quality.

### Checks

- citation quality
- unsupported claims
- outdated assumptions
- contradictions
- missing assumptions
- unrealistic financial outputs
- compliance risks

### Outputs

- validation memo
- source gap list
- contradiction report
- investor-readiness status

### Decision

Approved / revise / reject.

---

## 7. Outreach Narrative Agent

### Purpose

Convert intelligence into stakeholder-specific communication.

### Outputs

- investor brief
- county official memo
- landowner letter
- advertorial
- pitch narrative
- meeting prep brief

### Decision

Ready to send / revise / hold.

---

## 8. Orchestration Agent

### Purpose

Route tasks across agents, tools, and data sources.

### Responsibilities

- select correct agent
- load relevant context
- enforce validation
- prevent duplicate work
- send outputs to the right folder
- prepare final executive package

### Decision

Which agent acts next?
