# Stack Layer → Lender Type Coverage Map

This is the **bridge** between the capital stack design and the lender library. Use it to identify which lender categories to search when filling each layer.

## Layer 1 — Senior debt (50-70% of TPC)

| Project stage | Lender type | Examples (illustrative — validate before use) |
|---|---|---|
| Raw land | (rare) | Some CDFIs, A&D specialists |
| Land / horizontal | Land + A&D lenders | Builder Finance, Builders Capital, Enact Partners, Ready Capital, Kennedy Funding, Trez Capital |
| Vertical construction | Construction lenders (regional / national) | Local banks (UMB, Commerce, Central Bank KC, Paramount), bridge funds (ACORE, Parkview, Thorofare, Madison Realty, Bloomfield, Trez), institutional (PCCP, Mesa West, 3650 REIT, Starwood Mortgage, Ares, KKR, Blackstone Mortgage), BTR/SFR (Lima One, Kiavi, RCN, LendingOne, Anchor Loans, CoreVest) |
| Bridge / lease-up | Bridge lenders | Madison Realty, Thorofare, ACORE, Parkview, Ready Capital, Bloomfield, Trez |
| Permanent takeout | Permanent lenders | Life companies, CMBS, banks, Fannie/Freddie (multifamily) |

## LIHTC / NMTC overlays (subordinate stack)

| Program | Administering body | Typical use | Examples (illustrative) |
|---|---|---|---|
| 9% LIHTC | State HFA (e.g. MHDC in MO) | Affordable multifamily | Syndicators: Hunt Capital, Monarch, Raymond James |
| 4% LIHTC + tax-exempt bonds | State HFA + bond issuer | Larger affordable deals | Same syndicators |
| NMTC | CDFI Fund (federal) | Commercial in low-income census tracts | Allocatees: AltCap, Central Bank KC, IFF, Justine Petersen, GKC LISC |
| HTC (historic) | State historic preservation office | Historic rehab | National HTC syndicators |
| AHP / FHLB | FHLB Des Moines | Affordable multifamily / rural | Direct grants, max $3M/project (2026 round) |
| State / local programs | State HFA, city housing trust | Varies | KC Housing Trust Fund, KC Regional Housing Fund |
