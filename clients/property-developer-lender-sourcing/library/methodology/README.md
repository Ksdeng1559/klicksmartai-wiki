# Methodology

The 7-step playbook that turns an empty project intake into a routed, scored, drafted-out lender shortlist.

1. `01-intake.md` — capture project facts (sponsor, asset, market, deal size, stage, overlays, timeline)
2. `02-tam-tiering.md` — build the addressable lender universe in 4 tiers (local / regional / institutional / international)
3. `03-scorecard.md` — score each candidate against the intake (Geog 15% / Asset 15% / Stage 15% / Lev 15% / Size 10% / Sponsor 10% / Recourse 10% / Execution 5% / Channel 5%)
4. `04-outreach-playbook.md` — 7-touch plan customized to lane, jurisdiction, and channel
5. `05-compliance-routing.md` — 4-lane classification (CRE debt / residential MLO / mezz structured / securities-equity)
6. `06-referral-channels.md` — law-firm / CPA / wealth-mgr / broker pathways
7. `07-deliverables.md` — what to produce for the client (shortlist + stack map + outreach + TS model)

## Reference engagement

First validation: `~/wiki/clients/veritas-developments/` (Veritas Development Group LLC, 2026-08 onwards). The methodology was built there and generalized here.

## Per-project files

When starting a new developer project, copy this schema to `projects/<developer-slug>/` and run the 7 steps in order.

├── 01-intake.md
