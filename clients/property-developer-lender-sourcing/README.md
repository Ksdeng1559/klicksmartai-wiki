# Property Developer Lender Sourcing

**Methodology template for sourcing debt and equity capital for property developer clients.**

Scaffolded 2026-10-10 by Hermes. Re-uses methodology validated on `~/wiki/clients/veritas-developments/`.

## Start here

- `IDENTITY.md` — what this workspace is, what it produces
- `CONTEXT.md` — when to enter, stage transitions
- `_config/compliance.md` — 4-lane compliance routing (READ BEFORE ANY OUTREACH)
- `library/methodology/README.md` — 7-step playbook

## Library

- `library/lenders/` — lender profiles + index CSV (empty; populate per engagement)
- `library/capital-stack/` — 5-layer stack design + lender coverage map
- `library/methodology/` — intake, tiering, scorecard, outreach, compliance, referral, deliverable templates

## Reference engagement

- `~/wiki/clients/veritas-developments/` — Veritas Development Group LLC, first validation of this methodology

## How to use

1. New developer signs engagement letter
2. Capture intake per `library/methodology/01-intake.md` → `entities/<slug>.md` + `projects/<slug>/01-intake.md`
3. Run 7-step methodology (intake → tiering → scorecard → outreach → compliance → referral → deliverables)
4. Promote validated drafts to `projects/` and `deliverables/` per `drafts/VALIDATION_QUEUE.md`
5. Post-close, capture lessons in `STATUS.md` for the next engagement
