# Projects

One sub-folder per developer engagement. Each sub-folder has the **same internal structure** so methodology is repeatable.

## Sub-folder schema

```
projects/<developer-slug>/
├── 01-intake.md           # captured project facts
├── 02-capital-stack.md    # 5-layer stack design
├── 03-tam-lender-list.md  # tiered universe
├── 04-fit-scorecard.md    # scored against intake
├── 05-outreach-sequence.md # 7-touch plan
├── 06-referral-channels.md # law-firm / CPA / WM
├── 07-term-sheet-log.md   # TS received, evaluation
└── 99-post-close.md       # post-close capture (knowledge)
```

## When to create

When a developer signs an engagement letter. Do not create sub-folders for unengaged prospects.

## Promotion rules

- All files in `projects/` come from `drafts/` first
- Promotion requires Dennis (KlickSmartAI) approval + sponsor counter-approval
- See `../drafts/VALIDATION_QUEUE.md` for the gate
