# drafts-preview/

HTML previews of `drafts/` content for visual review. For this client, the typical preview is an HTML dashboard rendering the DuckDB analyst views (e.g. the PAA demand signals table). Per the ICM template: "drafts-preview" is auto-built by `build.py` when HTML renders are needed.
