# Executive Summary Generator

The user-facing deliverable of the LeadSniperAI enrichment process. Produces a
client-ready, decision-grade summary from the raw enrichment data.

## Position in the pipeline

```
Review Intelligence (signal confirmed GO)
        ↓
Enrichment (DataForSEO + Tavily + Exa + Deepline)
        ↓
★ EXECUTIVE SUMMARY (this document) ★
        ↓
Human review → outreach / decision
```

## The Executive Summary format

```markdown
# Executive Summary — {Business Name}

## Business Snapshot
- **Category:** {category}
- **Location:** {address}
- **Rating:** {rating}★ ({reviews} reviews)
- **Website:** {website}
- **Online presence:** {is_claimed ? "Claimed & verified" : "Unclaimed"}

## Confirmed Signal
- **Signal:** {signal — e.g. "capacity overload — booked out 3 weeks"}
- **Evidence:** {evidence — review themes, place_topics, hiring, news}
- **Confidence:** {high/medium/low}
- **Observed:** {date}

## Diagnosis
- **Phase:** {startup/growth/established/overloaded/declining}
- **Health score:** {0-100}
- **Key themes:** {dominant themes with % share}

## Opportunity
- **Recommended service:** {service #1}
- **Why:** {basis — theme/phase evidence}
- **Proof hook:** {outreach hook from reviews}

## Decision-Maker
- **Name:** {decision maker}
- **Title:** {title}
- **Contact:** {verified email / phone}
- **Verification:** {verified date + method}

## Recommended Next Action
- **Action:** {1-2 sentence recommendation}
- **Priority:** {high/medium/low}
- **Why now:** {urgency — why this timing}

---
*Generated by LeadSniperAI · {date} · Data: DataForSEO + Tavily + Exa + Deepline*
```

## Data sources per section

| Section | Source | Notes |
|---------|--------|-------|
| Business Snapshot | DataForSEO listings | rating, reviews, address, is_claimed, website |
| Confirmed Signal | Review Intelligence + place_topics | themes, health, phase |
| Diagnosis | Review Intelligence | phase + services |
| Opportunity | Review Intelligence | service recs + proof hooks |
| Decision-Maker | Tavily (people) + Deepline (email) | LinkedIn → verified email |
| Company context (optional) | Tavily `enrich_lead_full` | news, hiring, funding, tech stack |
| Deep discovery (optional) | Exa deep search | competitors, market context |

## Two output levels

1. **Compact (1-page)** — the format above. For decision-making, client-ready.
2. **Full (3-5 pages)** — compact + company intelligence (news, hiring, funding, tech stack) + competitor landscape + market context from Exa. For deeper stakeholder briefs.

## Implementation notes

- **Rendered as Markdown** (client-ready, can convert to Google Doc/PDF)
- **LLM-generated** when Gemini key present (best narrative quality)
- **Rules-templated** as fallback (works today without Gemini) — ✅ **BUILT + VERIFIED 2026-08-05**
- **Part of the enrichment flow** — auto-generated after signal confirmation, before outreach
- **HITL:** summary is for the user's use; never sent externally without approval

## Endpoint

`POST /api/v1/executive-summary` — accepts business snapshot + reviews + contact +
website fields; `auto_fetch: true` pulls DataForSEO business data automatically.
Returns `{ summary: <markdown>, meta: { phase, health_score, signal,
primary_service, decision_maker, contact_verified, method } }`.

Verified live (Milani Plumbing): full 8-section markdown summary generated from
DataForSEO auto-fetch + place_topics sentiment + review intelligence + contact.
Generator: `backend/app/services/executive_summary.py`.

## Manual-process usage (current phase)

combining:
