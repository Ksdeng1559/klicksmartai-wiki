# Research for Capital Formation — NotebookLM Prompt Stack
## Spectra Holdings

Purpose: reusable NotebookLM prompts for Spectra Holdings research, capital formation, county intelligence, Master Credit Facility strategy, investor narratives, grant intelligence, municipal partnership planning, and executive briefing generation.

---

## Recommended Usage Workflow

1. Upload source documents into NotebookLM.
2. Start with `Research Gap Detection Engine`.
3. Run `County Intelligence Report Generator`.
4. Run `Why-Now Signal Extractor`.
5. Run `Capital Stack Scenario Builder`.
6. Run `Investor Objection Handler`.
7. Convert outputs into investor one-pagers, board briefs, grant strategy memos, municipal partnership pitches, and capital formation briefings.
