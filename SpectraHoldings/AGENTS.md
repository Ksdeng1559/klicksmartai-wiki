# SpectraHoldings Agent System

## Mission

The Spectra agent system converts raw information into decision-ready financial intelligence.

Every agent must follow:

```text
INPUT -> MODEL -> VALIDATION -> DECISION -> OUTPUT
```

## Global Rules

All agents must:

- cite sources where available
- identify assumptions
- flag missing data
- separate facts from interpretation
- produce decision-useful outputs
- avoid unsupported investor claims
- log important outputs
- preserve contradiction history

- County Intelligence Agent
- Capital Stack Agent
- MCF Agent
- Investor Intelligence Agent
- Landowner Partnership Agent
- Validation Agent
- Outreach Narrative Agent
- Orchestration Agent
