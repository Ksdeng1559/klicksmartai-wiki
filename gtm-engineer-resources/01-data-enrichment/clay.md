## GTM Engineering Fit

### Pipeline Position
- **Enrichment + orchestration layer:** Takes signal input → enriches via 150+ providers → triggers automated workflows
- **vs. Apollo:** Clay is workflow-first (enrich → act); Apollo is channel-first (data + outbound in one)
- **vs. EnrichLayer:** Clay is a UI + workflow platform; EnrichLayer is a raw API
- **Best for:** Complex multi-step enrichment workflows with conditional logic

### Spectra Holdings Use Case
```
Funding signal detected → Clay Waterfall (Explorium + Apollo + EnrichLayer) → Claygent research →
enriched county contact → Klick2Client OS outreach → faith-framed advertorial
```

- Track job changes at CDFIs and Christian foundations in target counties
- Trigger enrichment workflows when new missionary org activity detected
- Automate routing to Klick2Client OS sequencing

### Complimentary Stack

| Layer | Tool | Role |
|-------|------|------|
| Signal detection | Apify / Explorium | Crawl + detect |
| Deep enrichment | Clay Waterfall | Multi-provider enrichment |
| Workflow orchestration | Clay Sculptor | Conditional routing + automation |
| Outbound execution | Klick2Client OS | LinkedIn + Email sequences |
| AI research agents | Claygents | Company + person deep dive |
