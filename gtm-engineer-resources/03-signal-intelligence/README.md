# Signal Intelligence Resources

*03-signal-intelligence/ — resources for detecting business signals: news, events, funding announcements, job changes, and social triggers that indicate a prospect is in-market.*

---

This category is being built out. Key resources to catalog:
- **News / media monitoring:** Native tools, RSS, API-based monitoring
- **Social listening:** Twitter/X, LinkedIn, Reddit signal detection
- **Government / regulatory feeds:** Grant announcements, regulatory changes, procurement
- **Event detection:** Conferences, webinars, new hires, promotions

For the Spectra Holdings pipeline, the signal intelligence layer monitors:
1. CDFI fund announcements (government feeds)
2. Missionary org activity in target counties (news + event)
3. Faith-based foundation grant cycles (news + regulatory)
4. County-level economic development signals (government + news)
