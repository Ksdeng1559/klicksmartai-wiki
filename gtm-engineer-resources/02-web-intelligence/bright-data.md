## GTM Engineering Fit

### Not a Direct Competitor
Bright Data is **infrastructure**, not enrichment. EnrichLayer gives structured API output; Bright Data gives raw scraping infrastructure. Use case:

- **Bulk company research** (IDC, CSE): One-time dataset purchases for market analysis
- **High-volume scraping beyond API limits:** When EnrichLayer/Scrapingdog hit limits
- **Primary path:** Start with EnrichLayer (structured) → escalate to Bright Data if needed

### Spectra Holdings Use Case
- Purchase Whatcom County / Bexar County org datasets for one-time market intelligence
- Use residential proxies for anonymized county government site crawling
- Feed into EnrichLayer for structuring before Klick2Client OS

### Complimentary Stack

| Layer | Tool | Role |
|-------|------|------|
| Infrastructure | Bright Data | Proxies + raw scraping |
| Structure | EnrichLayer | API enrichment |
| Outbound | Klick2Client OS | Lifecycle + sequencing |
